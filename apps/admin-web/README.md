# Hospital Administration & SaaS Platform Portal (`@healthcare-system/admin-web`)

Single-Page Web Application for Hospital Administrators (Chief, Coordinator, Accountant, HR-QC) and SaaS Platform Administrators.

## Directory Layout
- `src/features/` — Domain user journeys (staff onboarding, tenant provisioning, dashboards)
- `src/components/` — Design system primitives
- `src/layouts/` — Shell navigation & sidebar layouts
- `src/pages/` — Route entry points
- `src/services/` — Shared API client wrappers
