# Nurse Field Mobile Application (`@healthcare-system/nurse-app`)

React Native mobile application for certified hospital nurses providing home care visits:
- Pre-visit clinical briefing and patient address view (US-HP-18)
- Real-time GPS departure tracking and ETA calculation (BR-07)
- On-site geofenced check-in using patient in-app dynamic code (UC40)
- Mandatory initial clinical assessment (BR-22)
- In-session add-on item confirmation (BR-15)
- Mandatory care report submission upon visit conclusion (BR-22)
- Session termination and patient absent workflows (BR-16, BR-07)
