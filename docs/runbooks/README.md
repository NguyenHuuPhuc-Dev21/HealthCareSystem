# Operational Playbooks & Incident Runbooks

Standard Operating Procedures (SOPs) and runbooks for resolving the 4 standard platform incidents defined in **NFR-09.5**:
1. `F8-payment-gateway-failure.md` — Handling gateway downtime, webhook retries, and manual refund execution.
2. `BR10-clinical-ai-outage.md` — Failover to on-duty triage doctor review upon AI service interruption.
3. `BR23-unacknowledged-sos.md` — Procedures when emergency SOS alerts exceed 5-minute escalation SLAs.
4. `F7-reconciliation-discrepancy.md` — Investigating variances between payment gateway statements and internal ledgers.
